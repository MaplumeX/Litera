# Agent 读取章节时理解脚注

## 问题

`read_chapter` 返回的 Markdown 完全不认识脚注：

- 正文里的脚注标记 `<a epub:type="noteref"><sup>1</sup></a>` 被压平成紧贴正文的普通数字（`有涯1，`），agent 分辨不出这是注号还是正文数字。
- 带 `id` 的注号会被当作锚点，把所在段落从注号处劈成两个段落。
- 注释内容要么作为无标记的普通段落留在章末，要么放在单独的注释文件里（成为另一章），agent 读当前章节时看不到，也无法把它和注号对应起来。
- 长章节分 part 后，注号和章末注释往往不在同一个 part 里。

## 方案

解析 EPUB 时识别脚注引用，`read_chapter` 输出 Markdown 脚注语法：

- 注号渲染为 `[^label]`，`label` 取注号文本去掉括号和空白（`[1]` → `1`），为空或过长时用目标 id；同一文件内不同目标撞名时加 `-2`、`-3` 后缀。
- 每个 read_chapter part 末尾追加该 part 中出现的注号的定义：`[^1]: 注释内容`。注释可以在同一文件或其他文件里（跨文件尾注）。
- 注释内容取目标 id 所在元素；目标是行内元素（如尾注里 `<a id="n1">`）时向上取最近的块元素。注释里指回注号的回链被剥掉。

### 识别规则

候选链接是带 `#fragment` 的 `<a>`，且满足其一：`epub:type` 含 `noteref`、`role="doc-noteref"`、父元素是 `<sup>`、唯一的元素子节点是 `<sup>`。`epub:type`/`role` 为 backlink 的排除。

候选必须能解析到存在的目标元素。互相指向的一对候选（注号 ↔ 回链），阅读顺序在前者是注号，在后者是回链。

### 不变的部分

- 扁平文本 `text`（搜索、三元组索引）保留注号原文；Markdown/扁平一致性校验忽略注号。
- 注号不再作为锚点切分段落/segment。
- 注释原文仍留在原位置（不搬移、不删除），避免改变章节所有权。
- 引文定位（`locateQuote`）忽略 `[^label]` 标记，agent 引用时带不带注号都能匹配。

## 已知限制

- 一章由多个文件拼成且各文件注号编号重复、指向不同注释时，章内同名 label 取第一个定义。
- 仅 EPUB；未处理纯文本形式（无链接）的脚注。
