# 可配置阅读页脚

阅读界面的页脚允许用户分别选择左侧、中间、右侧的信息：章节名、全书进度、章节进度、时间、电量或不显示，也可整体关闭。设置即时生效并在重新打开后保留。

- 配置仅保存在当前设备的 localStorage；不加入 Book 的阅读设置、应用偏好或 Sync Manifest，不触发同步活动。
- 桌面设置提供「阅读页脚」入口，手机阅读设置提供相同配置和预览。
- 桌面保留进度条操作，在其下显示配置信息；手机分页模式使用页边距，滚动模式为页脚预留空间。
- Android 从原生接口读取电量，支持的桌面 WebView 使用 Battery API；无法获取时显示「—」，并提供无障碍说明。
- 仅在选择对应信息时更新时间或查询电量；返回前台时刷新电量。
- 仅有一个章节时不重复显示章节进度；长章节名截断，保留完整标题提示。
