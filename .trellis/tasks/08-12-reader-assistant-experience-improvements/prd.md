# 阅读器与助手体验完善

## Goal

父任务：统一规划 5 项阅读器与 AI 助手体验改进，分别交付到 3 个子任务中。

## Requirements

### 子任务 A：聊天面板消息交互增强（08-12-chat-message-interaction）

- **12 停止后重试**：用户中止流式回复后，保留原 prompt 文本，提供一键重发入口。
- **15 消息复制/编辑**：
  - AI 回复支持一键复制到剪贴板。
  - 用户消息支持编辑后重发（原消息保留为历史，新消息追加到末尾）。

### 子任务 B：会话重命名（08-12-session-rename）

- **13 会话重命名**：用户可修改会话标题；标题持久化到 sidecar 会话存储并同步到会话列表。

### 子任务 C：主题与设置入口统一化（08-12-theme-settings-unification）

- **17 主题全局化**：阅读器的 light/dark/sepia 主题同时作用于 App 外壳（书库页、工具栏、聊天面板），而非仅注入 foliate 渲染区。
- **18 设置入口统一**：在书库页与阅读器页提供统一的设置入口，可打开阅读偏好设置（字号/字体/主题）与 AI 配置。

## Acceptance Criteria

### 子任务 A

- [ ] 中止流式回复后，输入框保留原文本并显示"重试"提示，点击可重发。
- [ ] AI 回复消息上提供复制按钮，点击后复制纯文本到剪贴板。
- [ ] 用户消息上提供编辑按钮，点击进入编辑态，保存后以新消息形式重发。
- [ ] 现有发送/中止/会话切换流程不受回归。

### 子任务 B

- [ ] 会话列表中每个会话提供重命名入口。
- [ ] 重命名后新标题持久化，重启应用后仍显示新标题。
- [ ] sidecar 协议扩展（rename_session 命令 + session_renamed 事件）有类型定义。
- [ ] 现有会话创建/切换/删除流程不受回归。

### 子任务 C

- [ ] 切换主题时，App 外壳（书库页、顶栏、聊天面板）跟随变化。
- [ ] 书库页提供设置入口，可打开阅读偏好与 AI 配置。
- [ ] 阅读器页的设置入口保持可用，且同时包含阅读偏好与 AI 配置。
- [ ] 主题偏好持久化（无书时也能切换并生效）。

## Child Tasks

- `08-12-chat-message-interaction` — 聊天面板消息交互增强
- `08-12-session-rename` — 会话重命名
- `08-12-theme-settings-unification` — 主题与设置入口统一化

## Notes

- 子任务之间相互独立，可按任意顺序实现，但建议 A → B → C 的顺序（A 改动最局部，C 牵动状态架构）。
- 父任务本身不直接实现代码，仅持有跨子任务的需求集合与最终集成验收。
