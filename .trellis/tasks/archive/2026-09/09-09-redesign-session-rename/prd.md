# 重设计会话标题重命名交互

## 背景

当前会话列表（`src/components/chat/SessionList.tsx`）中的重命名交互：

- hover 会话行出现铅笔图标，点击后标题原位变为输入框
- 输入框右侧跟随「保存 / 取消」两个文字按钮
- Enter 保存、Esc 取消

存在的问题：

1. 「保存 / 取消」文字按钮占空间，视觉冗余
2. 输入框 `flex-1` 但缺少 `min-w-0`，长标题时输入框不收缩，导致行内容溢出容器

## 需求

1. 编辑态只保留输入框，移除「保存 / 取消」按钮：
   - Enter 确认保存
   - Esc 取消编辑
   - 失焦（blur，即点击别处）自动保存
2. 修复输入框溢出：输入框可正常收缩，不撑破行容器
3. hover 铅笔入口保持不变

## 验收标准

- [ ] 编辑态不再显示「保存 / 取消」文字按钮
- [ ] Enter 保存、Esc 取消、blur 自动保存
- [ ] blur 保存时与 Enter 保存行为一致（空标题视为取消）
- [ ] 长标题进入编辑态时输入框不溢出行容器
- [ ] 现有相关测试（ChatPanel.test.tsx 等）通过或相应更新

## 范围

- `src/components/chat/SessionList.tsx` — 编辑态 UI 简化 + 输入框样式
- `src/components/chat/ChatPanel.tsx` — blur 自动保存逻辑（如需在父层处理）
- 相关测试文件按需更新
