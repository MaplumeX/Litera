# ChatGPT-style conversation TOC hover rail

## Goal

把 Agent 工作区的对话目录改成 Paseo 那种安静刻度轨：长对话时在消息列左缘看到会话形状，悬停预览提问、点击跳转。阅读器侧栏聊天不再提供对话目录。

## Background

- 现有实现来自 `08-21-agent-user-message-toc`：标题栏 `List` 按钮打开 `UserMessageToc` 遮罩覆盖侧栏。跳转、暂停底部跟随、滚动跟踪当前用户消息已在 `src/components/chat/ChatPanel.tsx` 实现。
- `ChatPanel` 有两种布局：Agent 工作区 `variant="workspace"`（主列，左侧会话 rail）；阅读器 `variant="docked"`（默认约 22% 窗宽）。
- 参考 Paseo chat outline（`packages/app/src/agent-stream/chat-outline/rail.web.tsx`，PR #2792）：宽面板左缘安静刻度；每条用户提问一个 slot；当前项更长；指针附近 dock 式放大；悬停约 150ms 后浮出该条 2 行预览；少于 2 条提问时隐藏。
- 用户决定：阅读器不提供该功能；Agent 工作区用上述 Paseo 轨。不照搬 ChatGPT 的整列展开，也不做标题弹出列表。
- 不复制 Paseo 的约 918px 面板宽度门槛：Litera 工作区已经和书籍分栏，再套这条门槛会在「Agent + 打开的书」下把轨藏掉。工作区只要有至少两条用户提问就显示刻度轨。
- 前端派生即可，不改后端协议或持久化。不新增 Appearance 开关。

## Requirements

### R1. 目录内容

- 只收录当前会话用户消息，按原顺序。
- 每项用正文短预览（沿用 `userMessagePreview()`：折叠空白、默认截到 60 字）。
- 发送、编辑重放、切换会话后，刻度与当前 `state.messages` 同步。

### R2. 跳转行为

- 点击刻度平滑滚动到对应用户消息，不触发编辑、重发或会话切换。
- 主动跳离底部后，流式生成不得立刻拉回底部；用户滚回底部后恢复既有自动跟随。
- 预览是悬停/键盘焦点上的单条浮层，不是整列目录；指针离开或焦点离开后收起。点击跳转不额外关掉整条轨。

### R3. Agent 工作区形态

- 仅 `variant="workspace"` 且用户提问 ≥ 2 条时显示刻度轨。
- 轨叠在消息列左缘（会话列表右侧），不占布局宽度、不遮输入框。
- 每条提问一个 slot，slot 均分轨高（长对话可压缩）；当前阅读位置对应的刻度更长/更亮。
- 指针附近 dock 式局部放大；首次进入轨约 150ms 意图延迟，激活后沿轨移动立即切换预览。
- 悬停或键盘焦点时，在刻度右侧显示该条最多 2 行预览。
- 去掉工作区标题栏「对话目录」按钮。
- 预览用 1px 边框或一档表面色，不用 `shadow-*`（前端 chrome 约定）。

### R4. 阅读器

- `variant="docked"` 不渲染刻度轨、标题栏目录按钮、遮罩覆盖层。
- 阅读器侧栏无论多宽都不出现对话目录。

### R5. 可用性

- 空会话或只有 1 条用户提问时不显示轨。
- 不破坏会话列表、消息编辑、流式输出、会话切换。
- 刻度与预览有中英文可访问名称；刻度可键盘聚焦并激活跳转。
- 切换会话或书籍时，悬停/焦点预览不得残留上一会话内容。

## Acceptance Criteria

- [ ] AC1. 工作区当前会话有 ≥2 条用户提问时，消息列左缘出现刻度轨，按原顺序对应每条用户消息，不含助手回复。（R1, R3）
- [ ] AC2. 悬停一条刻度（过意图延迟）或键盘聚焦后，只显示该条提问预览；指针/焦点离开后预览消失。预览文本是规范化短摘要。（R1, R3）
- [ ] AC3. 点击刻度平滑滚到唯一对应用户消息；流式生成不会立刻拉回底部；滚回底部后自动跟随恢复。（R2）
- [ ] AC4. 滚动消息时，当前阅读位置对应的刻度呈「当前」态；点击跳转后该刻度成为当前项。（R3）
- [ ] AC5. 工作区标题栏没有「对话目录」按钮；无遮罩覆盖侧栏。（R3）
- [ ] AC6. `variant="docked"` 下，无论消息多少、侧栏多宽，都没有目录按钮、刻度轨或覆盖层。（R4）
- [ ] AC7. 空会话或仅 1 条用户提问时工作区不显示轨；切会话/切书后预览与当前项不残留。（R5）
- [ ] AC8. 刻度有中英文可访问名称，可用键盘聚焦并跳转；不挡住输入框，不破坏会话列表与编辑。（R5）

## Out of Scope

- 阅读器侧栏的任何对话目录入口（含拉宽后的 docked 聊天）。
- 用模型生成话题标题。
- 助手回复、工具调用、书籍章节混入同一份目录。
- 通过目录编辑、删除或重发消息。
- Appearance 设置里的开关。
- 复制 Paseo 的 daemon prompt index / 虚拟列表分页（Litera 消息已在前端完整持有）。
