# 完善书库功能

## Goal

把书库补成可日常管理的书架：能改正书名/作者/封面，能换排序和列表视图，能从卡片菜单进书籍详情，顶部能看到最近在读的几本书并继续读。

## User Value

用户打开应用就能接着读最近那几本，也能按自己的习惯浏览和整理书架，而不被错误的 EPUB 元数据卡住。

## Background / Confirmed Facts

- 启动进入书库网格：封面、书名、作者、进度条、按最近打开排序、按书名/作者搜索。导入支持多选、拖放、内容指纹去重、同路径覆盖确认。删除支持单本/批量确认，并清理 `sessions/<bookId>/`。
- `BookRecord` 已有 `title` / `author` / `coverPath` / `lastOpenedAt` / `lastFraction` / `importedAt`。`save_book_metadata` 只在导入 commit 时用（需要 `importId` + staged EPUB），导入后不能改元数据。
- 卡片没有菜单或详情。选择模式只能批量删除。点封面即打开书。`list_books` 只按 `lastOpenedAt` 倒序（没有则靠后，再按 `importedAt` 倒序）。
- `library.json` 与 `preferences.json` 均为 `schemaVersion: 1` 且 `deny_unknown_fields`。新的书库记录字段必须 `#[serde(default)]`。UI 浏览偏好（语言、默认阅读模式、TTS、chrome 字体）走 `localStorage`，不能写进 `preferences.json`。
- 前端只有 `LibraryView` 调用 `list_books`。阅读恢复、批注、TTS 已在阅读器侧完成，本任务不改那些路径。

## Key Decisions

- 编辑入口：菜单管动作，详情弹窗里改书名/作者/封面。点封面或列表行主体仍打开书。
- 菜单：网格卡片和列表行都有 ⋮；右键打开同一份菜单。菜单项只有打开、详情、删除。选择模式下隐藏菜单，点击仍是勾选。继续阅读横排可右键打开同一菜单。
- 继续阅读：顶栏下方单独一排，最多 4 本有 `lastOpenedAt` 的书，按最近打开倒序。不是跳回上一本的按钮，也不是顶栏工具条。空书库、从未打开过任何书、或正在搜索时不显示。这 4 本仍出现在下方主列表。不左右滑动。
- 主列表排序：最近打开、书名、作者、导入时间、进度。默认最近打开。选过的排序和网格/列表视图跨启动记住。继续阅读横排不受主列表排序影响。
- 列表行：封面缩略图、书名、作者、进度、最近打开。导入时间只在详情里看。窄窗口可隐藏「最近打开」列。
- 不改 EPUB 文件本体、不改 `bookId`、不把浏览偏好写入 `preferences.json`。

## Requirements

### R1 导入后可改书名、作者、封面

- 用户在详情弹窗中改已入库书籍的书名、作者、封面（封面用本机图片文件替换）。
- 保存后网格、列表、继续阅读横排、搜索、阅读器顶栏立即使用新值；重开应用后仍在。
- 只改 `library.json` 对应记录和 `books/<id>/cover.jpg`。不改 EPUB 本体、`bookId`、阅读进度、设置、批注、AI 会话。
- 书名不能为空。作者可以为空。不选新封面则保留原封面。
- 取消或关掉弹窗不写回任何已保存数据。

### R2 排序切换

- 主列表可切换：最近打开、书名、作者、导入时间、进度。
- 默认「最近打开」，规则与现在一致：`lastOpenedAt` 倒序，没有打开过的靠后，再按 `importedAt` 倒序。
- 书名、作者：不区分大小写升序；作者为空的排在后面。
- 导入时间：`importedAt` 倒序。
- 进度：`lastFraction` 倒序；没有进度的排在最后。
- 继续阅读横排始终按最近打开排，不受此项影响。
- 当前排序与网格/列表视图跨启动记住。

### R3 列表视图

- 可在封面网格和列表之间切换。
- 每一行：封面缩略图、书名、作者、进度、最近打开时间。
- 窄窗口可不显示「最近打开」；书名、作者、进度始终可见。
- 两种视图都能打开书、打开菜单、进入详情、删除。选择模式下列表行与卡片一样是勾选。

### R4 卡片菜单 / 书籍详情

- 网格卡片和列表行都有 ⋮；在卡片/行上右键打开同一菜单：打开、详情、删除。删除仍走现有确认框（含会话清理说明）。现有卡片 hover 删除入口保留。
- 详情是弹窗：可编辑书名、作者、封面；只读展示阅读进度和导入时间。保存后关闭并刷新书库。
- 选择模式下隐藏 ⋮ 和右键菜单。

### R5 继续阅读（最近几本）

- 书库内容区顶部（现有顶栏下方）展示最多 4 本最近打开过的书。点击即打开并恢复上次阅读位置。
- 一本都没打开过、书库为空、或搜索框有内容：不显示该区域。
- 这些书仍出现在下方主列表中。常见窗口宽度下 4 本并排，不横滑。

## Acceptance Criteria

- [ ] 能把一本书的书名、作者、封面改成自定义值；网格、列表、继续阅读、搜索、阅读器顶栏都显示新值；重开应用后仍在。
- [ ] 不选新封面时保留原封面。取消或关闭详情不改已保存数据。书名为空不能保存。
- [ ] 能在最近打开、书名、作者、导入时间、进度之间切换排序；主列表立刻按新规则排，继续阅读横排顺序不变。按进度时没有进度的书排在最后。
- [ ] 关掉应用再打开，仍使用上次的排序和网格/列表视图。
- [ ] 能在网格和列表间切换。列表行显示封面缩略图、书名、作者、进度、最近打开时间。两种视图都能打开书、打开菜单、进入详情。
- [ ] 网格卡片和列表行都有 ⋮，右键打开同一菜单：打开、详情、删除。点封面/行主体仍打开书。选择模式下没有卡片菜单，点击仍是勾选。
- [ ] 书库顶部最多展示 4 本最近打开过的书；点其中一本可继续读。从未打开过的书不出现。没有打开过任何书或正在搜索时不显示该区域。这 4 本仍在主列表里。
- [ ] 现有导入、去重、删除、阅读恢复、AI 对话不受损。不改 EPUB 文件、不改 `bookId`。

## Out of Scope

- EPUB 以外的格式
- 改 `bookId` 生成算法 / 把身份改成内容 hash
- 阅读进度云同步
- 阅读器内部能力（书内搜索、TTS、批注）
- 把改过的元数据写回 EPUB 文件
- 标签 / 分类 / 自定义书架
- 书库备份 / 导出
- 从 EPUB 重新抽取元数据
- 在系统文件管理器中显示书籍文件
- 单一「继续读最近一本」跳转按钮（已被 R5 取代）
- 从详情里清空封面（只能替换或保持）
- 排序升/降序切换（每种排序一种方向）
