# Expand book details metadata editing

## Goal

让书籍详情更适合整理书架：打开时不要立刻全选书名，并让用户能编辑简介、出版社、语言和系列。新导入时从 EPUB 自带元数据预填这四项。保存只写书架记录，不改 EPUB。

## User Value

用户进入详情是为了查看和整理，而不是马上覆盖书名。EPUB 里常有简介等信息，导入时应带到书架上；之后仍可在详情里改正。已经在书架上的书不自动补抽。

## Background

- 详情入口：书库卡片/列表/继续阅读的 ⋮ 或右键 →「详情」，弹窗是 `BookDetailsDialog`。
- 打开弹窗时 Radix Dialog 自动聚焦第一个可聚焦控件（书名 `Input`）。WebView 在 input 获得焦点时会全选文本。代码里没有显式 `select()` / `autoFocus`。
- 当前可编辑：书名（必填）、作者（可空）、封面（本机图片替换）。只读：阅读进度、导入时间。
- 导入时 `extractEpubMetadata`（foliate）只取 title / author / cover，经 `save_book_metadata` 写入 `library.json` 和 `cover.jpg`。导入之后卡片、搜索、详情、阅读器顶栏只读书架记录。
- `BookRecord.filePath` 是应用数据目录里的 `books/<id>/book.epub`。详情保存走 `update_book_metadata`：只改书架记录和可选封面，不改 EPUB。新字段必须 `#[serde(default)]`，不 bump `schemaVersion`。`BookRecord` 使用 `deny_unknown_fields`。
- 覆盖导入会替换书名/作者/封面，保留阅读进度、设置和对话（`library.overwriteDesc`）。
- Agent `get_book_metadata` 从存储的 EPUB 解析，不读书架记录。不写回 EPUB 时，详情里改的值不会出现在 Agent 那条路上。
- 搜索只匹配书名和作者。书名/作者上限各 4 KiB。
- 同类阅读器（KOReader / Foliate / Thorium / Readest）保存元数据也不写 EPUB；Calibre 也要显式 Embed/Polish 才写入文件。见 `research/reader-metadata-writeback.md`。

## Key Decisions

- 打开详情不自动聚焦、不全选书名。
- 新增可编辑字段：简介、出版社、语言、系列。全部可空，均为普通字符串（系列不是「系列名 + 册号」两个控件）。
- 字段只存在 `library.json`（封面仍是 `cover.jpg`）。不写回应用内 `book.epub`，也不写用户原文件。
- 新导入（含确认后的覆盖导入）从 EPUB 预填这四项；EPUB 里没有的项留空。简介若带 HTML，存成纯文本。
- 覆盖导入替换这四项，规则与现有书名/作者一致。
- 已经在书架上的书本次不回读 EPUB、不加「从 EPUB 填入」。旧书这四项为空，除非用户手填或以后覆盖导入。
- 不加标签/ISBN/出版年。卡片/列表/搜索不展示新字段。不改 Agent 元数据路径。

## Requirements

### R1 打开详情不要全选书名

- 打开书籍详情时，书名输入框不得自动获得焦点，也不得全选书名。
- 用户主动点击书名后再进入编辑。取消、保存、校验行为不变。

### R2 可编辑简介、出版社、语言、系列

- 详情弹窗在书名、作者、封面之外，可编辑：简介、出版社、语言、系列。
- 四个新字段均可为空。简介用多行文本，其余单行。
- 保存后写入对应书籍的书架记录；重开应用后仍在。详情再次打开显示已保存值。
- 不改 EPUB 本体、`bookId`、`contentHash`、阅读进度、设置、批注、AI 会话。
- 书名仍不能为空。取消或关掉弹窗不写回。
- 书库卡片/列表/继续阅读仍只展示书名、作者、封面；新字段只出现在详情里。
- 搜索仍只匹配书名和作者。

### R3 新导入从 EPUB 预填

- 新书导入 commit 时，从该 EPUB 读取简介、出版社、语言、系列，与书名/作者/封面一起写入书架记录。
- EPUB 缺少某项则该项为空，导入仍成功。
- 确认覆盖后的导入同样用新文件的这四项替换书架上的旧值（与书名/作者相同）。取消覆盖不改记录。
- 重复文件（duplicate）不重新抽取、不写记录。
- 不把预填或详情编辑写进 EPUB。
- 已入库且未再导入的书保持这四项为空。

## Acceptance Criteria

- [ ] 打开详情时书名不被全选，输入框也不自动聚焦。
- [ ] 能编辑并保存简介、出版社、语言、系列；再次打开详情和重开应用后仍在。
- [ ] 四个新字段都可以留空保存。取消/关闭不改已保存数据。书名为空不能保存。
- [ ] 新导入一本书后，详情里能看到 EPUB 里有的简介/出版社/语言/系列；没有的为空。
- [ ] 覆盖导入后这四项变成新文件里的值；取消覆盖则保持原值。
- [ ] 打开一本导入于本任务之前的书，详情里这四项为空，也不会在打开书库或详情时被自动填上。
- [ ] 保存详情后 `book.epub` 字节和 `contentHash` 不变。
- [ ] 网格、列表、继续阅读、搜索、阅读器顶栏的现有展示不因新字段改版。
- [ ] 现有书名/作者/封面编辑、导入、去重、删除、阅读恢复不受损。不改 EPUB、不改 `bookId`。

## Out of Scope

- 把改过的元数据写回 EPUB（应用内副本和用户原文件都不写）
- 已入库书籍回读 EPUB / 详情里「从 EPUB 填入」
- 标签 / 分类 / 自定义书架
- ISBN / 出版年
- 从详情清空封面
- 把新字段展示到卡片/列表或纳入搜索
- 让 Agent `get_book_metadata` 改读书架记录
- EPUB 以外的格式
- 阅读进度编辑
- 系列名与册号拆成两个字段
- 导出/另存为独立 EPUB 到自选路径
