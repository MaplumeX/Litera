# Improve new session UX

## Goal

修现有「会话列表 → 新建会话」路径：点完立刻看到空白对话，标题和空状态用中文且语义正确。当前已是空会话时不重复创建。不加顶栏一键入口。

## Background

- 入口只在覆盖式会话列表：`ChatPanel` 顶栏用 `MessagesSquare` 打开列表，`SessionList` 顶部才有「新建会话」（`src/components/chat/ChatPanel.tsx`、`SessionList.tsx`）。
- 点击调用 `newSession()` → sidecar `new_session` → `session_created`。reducer 设为当前会话、清空消息，并乐观插入列表，默认标题 `"New Session"`（`src/lib/agent-reducer.ts:173-186`）。sidecar 无自定义名、无首条消息时同样回落到 `"New Session"`（`sidecar/index.ts:697-700`）。
- 建完后覆盖层不关，空白对话被挡住。
- 空会话在第一条消息前不落盘（pi `SessionManager`；archived `08-12-fix-new-session-list`）。列表靠乐观条目撑着。
- 无消息时空状态副文案固定为「打开一本书，选中段落或直接提问。」（`EmptyState.tsx`），书已打开时也不变。
- 打开书且没有活动会话时，自动切到 `sessions[0]`（`ChatPanel.tsx:96-106`）。
- 流式生成中禁用新建/切换。

## Requirements

- R1 点击会话列表里的「新建会话」后，覆盖式列表关闭，用户看到目标会话的空白对话区，输入框获得焦点。
- R2 当前已有活动会话且消息列表为空时，不再调用 `new_session`：只关列表并聚焦输入（复用当前空会话）。
- R3 需要真正新建时（当前无活动会话，或当前会话已有消息），走现有 `new_session` 协议；成功后执行 R1。
- R4 空会话默认标题为「新会话」。前端乐观插入与 sidecar `deriveTitle` 回落保持一致。首次发消息后仍按现有逻辑用首条消息截断替换标题（或用户重命名）。
- R5 书已就绪且会话无消息时，空状态副文案为「选中段落，或直接提问。」建议提问按钮逻辑不变。书未就绪时仍提示需要先打开书。

## Out of Scope

- 不加顶栏一键新建按钮。
- 不改 sidecar 空会话落盘策略。
- 不重做整块聊天面板视觉。
- 不改发送、停止、重命名、删除、切书恢复的协议语义。
- 流式生成中仍禁用新建/切换。
- 不在新建时删除其它空会话。

## Acceptance Criteria

- [ ] AC1 在已有消息的会话里打开列表，点「新建会话」：列表关闭，消息区为空，输入框有焦点，列表中新条目标题为「新会话」且为当前会话。
- [ ] AC2 当前已是空会话时再点「新建会话」：不新增列表条目，列表关闭，仍停留在同一会话，输入框有焦点。
- [ ] AC3 书已打开、会话无消息时，空状态不出现「打开一本书」。
- [ ] AC4 书未就绪时，空状态仍提示需要先打开书。
- [ ] AC5 新会话发出第一条消息后，标题按现有规则更新，不再显示英文 `New Session`。

## Key Decisions

- 只修列表内现有路径，不加顶栏入口。
- 建完关覆盖层并聚焦输入。
- 默认标题「新会话」。
- 当前空会话复用，不连点堆条目。
