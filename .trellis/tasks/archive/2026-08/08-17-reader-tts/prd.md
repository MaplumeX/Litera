# Reader TTS playback

## Goal

用户在已打开的 EPUB 里可以像常见阅读器一样听书：一键朗读正文，句级跟读高亮，读完自动往后走；自己跳到新位置后，从新画面接着听。

## Background

Litera 是带阅读助手的跨平台 EPUB 阅读器（Tauri + React + foliate-js）。早期产品文档把 TTS 标为 v2 候选，并明确它是阅读器功能，不是 agent 工具。

应用层目前没有朗读入口：`ReaderViewHandle`、顶栏、设置、选区工具条、i18n 都没有 TTS。`src/foliate-js/tts.js` 已有分块 / 分词 / SSML / `setMark` 高亮；`view.initTTS()` 按当前文档建 `TTS` 实例。foliate-js **不负责发声**，只返回 SSML。`view.js` 另有 EPUB Media Overlay（SMIL 预录音频）路径，与本任务无关。

`PreferencesDataRaw` 使用 `deny_unknown_fields`。locale、默认阅读模式、界面字体已规定不得写入 `preferences.json`，走 `localStorage`。阅读页顶栏已有返回、目录、标注、标题、字体、模式、对话、窗口按钮；进度条在书页底部。空格目前不用于翻页（仅左右方向键）。

## Requirements

- **R1** 仅在已打开的书里提供朗读。书库页不出现朗读控件。书页被收起（Agent 模式隐藏书）时禁用播放并停止已在进行的朗读。
- **R2** 朗读对象是当前书的正文，不是聊天消息。
- **R3** 顶栏提供播放 / 暂停图标。空格同样播放 / 暂停；焦点在输入框、滑块、对话框等可编辑控件时不抢空格。
- **R4** 开始朗读后，书页底部、进度条上方出现播放条，含暂停、停止、语速、声音。停止朗读或离开阅读页后收起。语速 / 声音不放进设置页，也不用顶栏弹出层。
- **R5** 按下播放时：若书页里有未折叠选区，从选区起点开始；否则从当前可见页开头开始。
- **R6** 朗读当前句并做句级跟读高亮。该高亮不得写入标注文件，也不得覆盖或改写用户已保存的高亮 / 书签。
- **R7** 当前页 / 章节读完后自动翻到下一页或下一章，直到书尾后停止并收起播放条。
- **R8** 用户可调语速，并在系统已安装语音中选择声音。默认优先匹配界面语言 / 书籍语言的系统语音；没有可用语音时播放失败并给出可理解的提示，不崩溃。
- **R9** 发声使用系统 Web Speech API，接 `foliate-js` 的 TTS 分片。不接云端语音或本地神经网络引擎。Linux 中文音质取决于系统语音，本轮不另做补偿。
- **R10** 语速和所选声音写入 `localStorage` 键 `litera.ttsRate` / `litera.ttsVoice`（与 `litera.uiFontSize` 同类扁平键），不扩展 `preferences.json` 或 `save_preferences`。
- **R11** 返回书库、换书、卸载阅读页时必须停止朗读并清掉跟读高亮。
- **R12** 用户在朗读中主动换位置（点击 / 滚轮翻页、点目录、拖进度条、跳到标注）时：停掉当前句，从新可见位置开头继续朗读。朗读自己带动的自动翻页不算用户跳转，继续往下读。
- **R13** 朗读不得改写已有进度持久化语义。自动翻页产生的位置变化仍按现有 `onRelocate` 路径保存进度。
- **R14** 用户可见文案走 `zh-CN` / `en` 目录和 `useT()` / `t()`。

## Out of Scope

- EPUB Media Overlay / 预录音频
- 云端或本地神经网络语音
- 锁屏、系统媒体键、后台听书、上一句 / 下一句跳转
- Agent 把书读出来当工具
- 非 EPUB 格式
- 选区工具条上的独立「朗读」按钮（选区只作为播放起点）
- 把语速 / 声音写入 `preferences.json`

## Acceptance Criteria

- [ ] **AC1** 打开一本书后，顶栏出现可点击的朗读按钮；书库页没有该按钮。（R1, R3）
- [ ] **AC2** 按播放后开始出声，播放条出现；再按暂停则静音并保持位置；再按播放从暂停处继续；按停止则静音、清高亮、收起播放条。（R3, R4）
- [ ] **AC3** 有选区时按播放，朗读从选区起点开始；无选区时从当前可见页开头开始。（R5）
- [ ] **AC4** 朗读过程中当前句有跟读高亮；停止后高亮消失；用户已保存的高亮 / 书签仍在。（R6）
- [ ] **AC5** 一页读完后自动翻到下一页或下一章并继续出声；全书读完后停止并收起播放条。（R7）
- [ ] **AC6** 播放条可改语速和系统语音；改完立即作用于后续语句；重启应用后仍是上次的语速和声音。（R8, R10）
- [ ] **AC7** 朗读中点目录、拖进度条或翻页后，声音从新画面继续，而不是停住或仍读旧位置。（R12）
- [ ] **AC8** 空格在阅读页切换播放 / 暂停；焦点在聊天输入框或设置对话框时，空格不触发朗读。（R3）
- [ ] **AC9** 返回书库或换书后没有残余朗读声，也没有残留跟读高亮。（R11）
- [ ] **AC10** 系统没有可用语音时，界面给出失败提示，应用不崩溃。（R8）
- [ ] **AC11** zh-CN 与 en 目录含有本功能全部新文案，键集合一致。（R14）

## Technical Notes

- 宿主把 foliate-js 返回的 SSML 解析成句子文本再交给 Web Speech；一句一条 utterance，开始时调用 `setMark`。多数 WebView 不执行 SSML。
- 同章内翻页不必重做 `initTTS`（同一 iframe `doc`）。换章 / `close` 后必须重做。
- 跟读高亮用独立 overlayer 键，不要用 `addAnnotation`，也不要用 `initTTS` 默认的 `select=true` 高亮。
- 类型补丁写在 `src/foliate-js.d.ts`，不要改 foliate-js 子模块源码。
