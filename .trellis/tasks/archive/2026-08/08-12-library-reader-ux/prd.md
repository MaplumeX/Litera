# Library & Reader UX Overhaul

## Goal

将 Litera 从"打开即读"的工具改造为具有完整书库管理与增强阅读体验的桌面阅读器：启动进入书库视图，选择书籍后进入阅读界面，阅读界面补齐目录导航、字体调节、主题切换等主流阅读器能力，并保留现有 AI 对话功能。

## User Value

用户获得接近主流阅读软件（如 Apple Books、Calibre Reader、readest）的完整阅读体验：书库管理（导入/删除/封面/搜索）+ 阅读界面增强（目录跳转、字体/主题个性化），降低"这不像个阅读器"的违和感，同时不丢失已有的 AI 选段问答能力。

## Background / Confirmed Facts

### 现有代码状态（已勘察）

- **应用入口**（`src/App.tsx`）：启动即为空阅读视图，顶部"打开文件"按钮 → 选文件 → 直接阅读 + 聊天分栏。无书库概念，无"最近阅读"。
- **阅读视图**（`src/components/ReaderView.tsx`）：仅封装 `<foliate-view>`，暴露 `prev/next`。无目录侧边栏、无进度跳转、无字体/主题控制。
- **聊天面板**（`src/components/ChatPanel.tsx`）：已实现选段问答 + 多会话管理 + 流式输出，功能完整。
- **Rust 后端**（`src-tauri/src/lib.rs`）：仅有 `open_file`（弹对话框读字节返回）+ sidecar 管理 + 会话命令。无书籍元数据持久化、无书库存储。
- **foliate.js 能力**（已确认）：`<foliate-view>` 自定义元素支持 `book.toc`（目录树）、`book.metadata`（标题/作者）、`book.getCover()`（封面 Blob）、`goTo(target)`/`goToFraction(frac)`（导航跳转）、`getSectionFractions()`/`getProgressOf()`（进度）。字体/主题通过 `view.renderer.setStyles(css)` 实现（foliate.js Paginator 内置，自动在 section 加载后重新应用）。
- **现有任务关系**：`08-11-agent-epub-reader` PRD 把"书库管理"明确列为 v2 Out of Scope。本任务是独立的 UI/UX 重构，不改动 sidecar/agent 工具协议。

### 技术栈（沿用现有）

- Tauri + React + Vite + TS + Tailwind + shadcn/ui + react-resizable-panels
- foliate.js（git submodule）
- 书籍持久化需新增：Tauri app data 目录存储书库元数据（JSON）

## Key Decisions

- **书库管理范围 = 完整管理**：导入（文件选择器 + 复制到 app data）、删除、封面网格展示、搜索/筛选。
- **阅读界面增强 = 目录 + 字体调节 + 主题**：目录侧边栏（点击跳转）、字体大小/字体族调节、主题切换（白天/夜间/护眼）。
- **视图流程 = 书库 → 阅读 → 返回书库**：启动进入书库，点击书进入阅读，阅读界面有"返回书库"入口。
- **书籍文件存储 = 复制到 app data**：导入时将 epub 复制到 Tauri app data 目录 `books/` 下，书库自管理副本；删除书时删除记录 + 副本文件。
- **阅读位置恢复 = 自动恢复上次位置**：每本书记录上次阅读位置（fraction），重开时自动跳转到该位置。

## Requirements

### 书库视图
- 应用启动默认进入书库视图，展示已导入书籍的封面网格。
- 用户能通过"导入"按钮打开文件选择器导入 `.epub` 文件。
- 书库持久化：导入的书籍记录持久化，重开应用后仍在。
- 书库每本书展示：封面、书名、作者。
- 用户能从书库删除书籍（删除记录 + 已复制的文件）。
- 书库支持按书名/作者搜索筛选。
- 用户点击书库中的一本书 → 进入阅读界面。

### 阅读界面
- 阅读界面有"返回书库"入口，可回到书库视图。
- 目录侧边栏：展示章节列表（来自 `book.toc`），点击章节跳转到对应位置。
- 字体调节：字体大小、字体族可调，设置在阅读期间即时生效。
- 主题切换：至少白天/夜间/护眼三种主题，即时生效。
- 保留现有 AI 对话面板（选段问答、多会话管理）功能不变。
- 保留现有翻页（上一页/下一页）与进度显示。
- 阅读位置恢复：重开同一本书时自动跳转到上次阅读到的位置（fraction）。
- 阅读设置（字体、主题）持久化：重开同一本书后恢复上次的设置。

### 打开书籍
- 从书库点击书 → 用持久化的文件路径打开（无需每次重新选文件）。
- 仍保留"打开文件"入口（导入新书的途径）。

## Acceptance Criteria

- [ ] 能在书库中搜索/筛选书籍。
- [ ] 能从书库删除书籍，删除后不再出现在书库中。
- [ ] 点击书库中的书 → 进入阅读界面，正确渲染分页阅读。
- [ ] 阅读界面有"返回书库"入口，点击后回到书库视图。
- [ ] 目录侧边栏显示章节列表，点击章节能跳转到对应位置。
- [ ] 字体大小和字体族可调，调整即时生效于阅读内容。
- [ ] 能在白天/夜间/护眼主题间切换，切换即时生效。
- [ ] 字体与主题设置持久化：重开同一本书后恢复上次的设置。
- [ ] 重开同一本书时自动恢复到上次阅读到的位置。
- [ ] 现有 AI 对话面板功能（选段问答、多会话、流式输出）不受影响。

## Out of Scope

- 书籍分类/标签/自定义集合（v2 候选）
- 阅读进度云同步（v2 候选）
- 书签、高亮、笔记（v2 候选，原 PRD 亦列为 v2）
- TTS、翻译、词汇解释（v2 候选）
- 书库排序方式切换（按书名/作者/最近阅读）——MVP 仅提供搜索筛选
- sidecar / agent 工具协议改动
- 跨书全局会话列表
