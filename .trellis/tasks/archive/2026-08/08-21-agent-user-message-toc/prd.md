# Agent 用户消息目录跳转

## Goal

为 Litera 内嵌 Agent 的长对话提供类似文档目录（TOC）的导航：用户可以浏览当前会话中的历次提问，并点击任一目录项快速滚动到对应的用户消息，减少手动翻找成本。

## Background

- 用户明确要的是“类似 TOC 的东西”，而不是单纯的上一条/下一条按钮。
- 当前聊天界面由 `src/components/chat/ChatPanel.tsx` 渲染；消息列表来自 `state.messages`，每条消息通过 `role: "user" | "assistant"` 区分。
- 当前会话已有独立的消息滚动容器；切换会话时会替换消息列表并回到底部。
- Agent 工作区左侧已有会话列表 rail，右侧可能显示书籍；阅读器模式下聊天面板宽度较窄。因此目录的呈现方式需要同时考虑宽、窄两种布局。
- 该能力可完全由前端根据当前会话消息派生，不需要新增后端协议、持久化字段或会话迁移。

## Requirements

### R1. 目录内容

- 只收录当前会话中的用户消息，不收录助手回复、工具调用或压缩状态。
- 目录项按消息在会话中的顺序排列。
- 每项使用用户消息正文生成可辨识的简短预览；长文本需要截断，多行文本需要适合目录展示。
- 新提问、编辑并重放历史提问、切换会话后，目录内容必须跟随当前 `state.messages` 更新。

### R2. 跳转行为

- 点击目录项后，聊天消息容器平滑滚动到对应用户消息。
- 跳转目标应落在易于阅读的位置，且不能触发消息编辑、重新发送或会话切换。
- 主动跳离底部后，不应被正在生成的助手内容立即拉回底部；用户再次滚到底部时恢复既有自动跟随行为。

### R3. 可用性与兼容性

- 空会话时不展示无意义的目录项。
- 用户消息目录不能遮住输入框，也不能破坏现有会话列表、消息编辑、流式输出和会话切换行为。
- 提供中英文可访问名称；目录触发器及目录项可通过键盘操作。
- 同时支持 Agent 工作区和阅读器侧边聊天两种 `ChatPanel` 布局。

### R4. 展示形态

- 在聊天标题栏提供“对话目录”按钮。
- 点击按钮后，以聊天面板内部的覆盖式侧栏展示目录；关闭后不占用消息区、书籍区或会话列表的布局宽度。
- 覆盖层必须可明确关闭；点击目录项完成跳转后自动关闭。
- 切换会话时不得残留上一会话的目录内容或打开状态。

### R5. 当前消息指示

- 目录打开时，必须高亮消息区当前阅读位置对应的用户消息。
- 用户滚动消息区时，高亮项随所在消息段更新；点击目录项跳转后，对应项成为当前项。
- 当前项变化不得反向抢夺用户对目录列表的手动滚动，除非当前项已经完全离开目录视口。

## Acceptance Criteria

- [ ] AC1. 当前会话有多条用户消息时，目录按原顺序列出每条提问的简短预览，且不混入助手消息。（R1）
- [ ] AC2. 点击任一目录项，消息区域平滑滚动到唯一对应的用户消息，随后目录自动关闭。（R2, R4）
- [ ] AC3. 跳转到历史消息后，流式生成不会立即把视图拉回底部；滚回底部后既有自动跟随继续工作。（R2）
- [ ] AC4. 发送新提问、编辑历史提问导致会话重放、切换会话时，目录与当前消息列表同步。（R1）
- [ ] AC5. 空会话、Agent 工作区和阅读器侧边聊天中均无布局遮挡或现有功能回归。（R3）
- [ ] AC6. 目录入口和目录项有中英文可访问名称，并可通过键盘打开和跳转。（R3）
- [ ] AC7. 点击标题栏按钮后，目录作为聊天面板内部的覆盖式侧栏打开；关闭或跳转后恢复原消息区且不改变其他栏宽。（R4）
- [ ] AC8. 滚动聊天内容时，目录高亮当前阅读位置对应的用户消息；点击跳转后对应目录项成为当前项。（R5）

## Out of Scope

- 全局搜索所有书籍或所有会话中的消息。
- 修改会话存储格式、Agent 协议或后端数据。
- 给助手回复、工具调用或书籍章节建立同一份混合目录。
- 通过目录执行编辑、删除或重新发送消息。

## Notes

- 当前最可能的改动集中在 `ChatPanel`、一个新的对话目录组件、i18n 文案及对应前端测试。
- 任务预期为轻量前端功能，产品形态确定后可采用 PRD-only 规划。
- 当前没有阻塞实现的产品问题；滚动位置跟踪与目录项可见性应复用项目已有的 ref、滚动容器和 TOC 当前项居中约定。
