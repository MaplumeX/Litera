# Fine-tune reader typography settings

## Goal

阅读排版按连续值精调，并补上字间距、段距、首行缩进。书库改全局默认，阅读中改当前书，可恢复默认。

## Background

上一轮设置页把字号锁在 S/M/L/XL，行距/页边距做成三档枚举。用户认为可调项不够，且挡位不能精调。

当前事实：

- 设置页 `SettingsPage`：排版 / 外观 / AI。控件全是挡位按钮。
- 字号/字体只按书保存，书库页禁用。行距/边距/对齐是全局默认 + 单书覆盖。主题只全局。
- 生效只走 `generateStylesCss` → `view.renderer.setStyles`。
- 后端校验是封闭枚举：`fontSize` 只能是 14/16/18/20；`lineHeight: "1.7"` 会被拒。
- `preferences.json` 保持 `schemaVersion = 1`。`update_reading_state` 整对象替换 `settings`。两份存储都是 `deny_unknown_fields`。

## Requirements

### R1 精调项

- 字号、行距从挡位改为连续精调。
- 「页边距」拆成版心宽度（`max-width`）和左右内边距（`padding-inline`）两条精调。不拆上下左右。
- 新增字间距、段距、首行缩进，同样精调。
- 字体、对齐、主题继续用选项按钮。

### R2 作用域

- 除主题外，全部排版项统一为：书库改全局默认，阅读中改单书覆盖，该项旁可「恢复默认」。
- 主题仍只全局。
- 书库设置页不再禁用字号/字体。
- 旧书里已存的字号/字体仍算该书覆盖。

### R3 控件与预览

- 连续量用滑条，旁显示当前数值。
- 不设设置页正文预览，不改为阅读中浮层。返回阅读页后 CSS 再生效。

### R4 兼容

- 旧行距枚举读成 1.4 / 1.7 / 2.0。
- 旧页边距枚举读成 36em+1.25rem / 42em+1.75rem / 52em+2.5rem。已有新字段时以新字段为准。
- 已有只含 theme 的 `preferences.json` 不得被整份重置。
- 不改设置页信息架构、返回路径、聊天齿轮只开 LLM 弹窗。

## Acceptance Criteria

- [ ] 排版页可以用滑条精调字号、行距、版心宽度、左右内边距、字间距、段距、首行缩进，并看到当前数值。
- [ ] 字体、对齐、主题仍是选项按钮。
- [ ] 书库改上述排版（含字号/字体）后，新开一本没有覆盖的书使用这些默认值。
- [ ] 阅读中改其中一项只影响当前书；「恢复默认」后该项回到全局默认。
- [ ] 主题仍全局，外壳和阅读区都跟随。
- [ ] 旧书 `lineHeight: "compact"` 读成 1.4；旧书 `pageMargin: "wide"` 读成 52em / 2.5rem。已存字号 18 的书仍是 18，并显示可恢复。
- [ ] 只含 theme 的旧 `preferences.json` 升级后主题不被重置。
- [ ] 聊天齿轮仍只打开 LLM 弹窗。
- [ ] `npm test` + `npm run build` 通过；相关 Rust 测试通过。

## Out of Scope

- 自定义字体、系统字体选择器
- 自定义主题、亮度、定时夜间模式
- 上下左右独立边距
- 设置页假文预览、阅读中排版浮层
- 书签、高亮、笔记、TTS、翻页手势、快捷键
- 改 LLM 配置

## Technical Notes

- 连续量存 JSON number，区间校验，不再用封闭枚举（对齐除外）。
- `lineHeight` / `pageMargin` 必须能读旧字符串。新写入不再写 `pageMargin`。
- `preferences.json` 不 bump schema。新键 `serde(default)`。`save_preferences` 读-改-写。
- 单书快照只包含仍覆盖的键。字号/字体不再强制写入每本书。
- 新键一旦写出，旧构建的 `deny_unknown_fields` 会把偏好文件当成损坏并重置主题。本任务与下一版必须一起发布。
- 段距/缩进注入到 `p`，字间距注入到 `html, body`。

## Ranges

| 项 | 单位 | 范围 | 步长 | 内置默认 |
|---|---|---|---|---|
| 字号 | px | 12–32 | 1 | 16 |
| 行距 | — | 1.2–2.4 | 0.05 | 1.7 |
| 版心宽度 | em | 28–60 | 1 | 42 |
| 内边距 | rem | 0.5–4 | 0.25 | 1.75 |
| 字间距 | em | -0.05–0.2 | 0.01 | 0 |
| 段距 | em | 0–2 | 0.05 | 1.0 |
| 首行缩进 | em | 0–3 | 0.1 | 0 |
