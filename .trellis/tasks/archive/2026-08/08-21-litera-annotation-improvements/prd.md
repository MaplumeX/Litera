# Improve Litera annotation features

## Goal

读者能在原文上点开已有高亮，改颜色、写笔记、删除；新划线支持固定色板。标注从「能钉、能划」变成日常能改、能记的工具。

## User Value

现在划完只能去侧栏找摘录删除，颜色写死，也不能写下为什么划。页内可操作 + 笔记 + 多色之后，划线才像阅读器里的标注，而不是一次性痕迹。助手按需查看标注时也能用上颜色和笔记。

## Background / Confirmed Facts

- 上一轮 MVP（`08-14-reader-bookmarks-highlights`）只做书签 + 单色高亮 + 左侧标注抽屉。当时明确不做笔记、多色、导出、点正文高亮菜单。
- 当前数据：`books/<id>/annotations.json`，`schemaVersion: 1`。
  - 书签 `{ id, cfi, fraction, createdAt, label? }`
  - 高亮 `{ id, cfi, excerpt, createdAt }`，无 `note`、无 `color`
- 高亮颜色是前端常量 `#fbbf24`，不落盘。`draw-annotation` 一律用这一色。
- 加高亮只能走选中浮层「高亮」；删/跳只能走标注抽屉。正文 overlay 的 SVG 是 `pointer-events: none`；foliate 已有 `show-annotation`（iframe click 命中已有高亮）。
- 章节 iframe 左右三分之一单击会翻页（`bindPointerPaging`）。点高亮必须先吃掉这次点击，不能翻页。
- 书签只能钉当前位置；`label` 来自章节名，侧栏不能改名。
- 同一 CFI 不加第二条书签/高亮。覆盖导入保留文件；删书带走 `books/<id>/`。
- 后端 `deny_unknown_fields`。缺文件 → 空列表。未知字段或错误 schema → `StorageCorrupt`。
- 助手可只读 `list_annotations`，不能写标注。点工具结果跳转后来被撤掉。
- 工作分支：`feat/litera-annotation-improvements`。

## Key Decisions

- **范围 = A+B+C**：点正文高亮弹出操作 + 高亮笔记 + 多色。不做导出。
- 笔记和颜色只挂在高亮上，不给书签加笔记/颜色。
- **交互**：选中后一键「高亮」立刻落下；改色、写笔记、删除都点这条已有高亮。选中浮层仍只有「高亮」和「问 agent」。
- 新高亮用**上次在弹层里选过的颜色**；本进程还没选过则用默认琥珀黄。上次颜色只活在进程里，不写磁盘。
- 侧栏继续负责列表、跳转、删除，并展示色点和笔记摘要。点击侧栏高亮仍跳转并关抽屉，不自动打开编辑弹层。
- `list_annotations` 按需返回高亮的 `color` 和有内容时的 `note`，仍只读，不注入每一轮上下文，助手不能改标注。
- 色板是固定小集合（设计里定 5 色语义 id），不接受自定义色值。
- `annotations.json` 保持 `schemaVersion: 1`。`color` / `note` 为可选字段；缺省旧文件必须能被新构建读取。

## Requirements

### R1 点正文高亮

- 选中后点「高亮」立即画上，不弹出色板或笔记框。
- 点击已画在原文上的高亮，打开宿主弹层（不进 iframe）。
- 弹层能改色、写/改笔记、删除这条高亮。
- 点高亮不得触发左右翻页。
- 删除后原文颜色消失，列表不再出现。
- 点空白、Esc、或开始新选区时关闭弹层。
- 侧栏点击高亮仍跳转到该处并关闭抽屉（与现在一致）。

### R2 笔记

- 每条高亮可有一段纯文本笔记。无笔记是合法状态。
- 侧栏高亮项在摘录之外能看出有无笔记（摘要）。
- 重开书、重开应用后笔记仍在。

### R3 多色

- 高亮颜色来自固定小色板，以语义 id 持久化在该条记录上。
- 新划线用上次在弹层里选过的颜色；进程内尚未选过则用默认色（当前琥珀黄）。
- 原文绘制用该条颜色；翻页、重开后颜色仍对。
- 旧记录没有颜色字段时，按默认色绘制，不丢记录。
- 侧栏能区分不同颜色。

### R4 助手只读

- `list_annotations` 每条高亮带 `color`（缺省则默认色）；`note` 有内容才带上，空笔记省略。
- 书签返回值不变。
- 不调用 `save_annotations`，不把标注注入书快照或 `readingContext`。

### R5 既有行为

- 选中浮层仍有「高亮」和「问 agent」。
- 书签、标注抽屉开闭、覆盖导入保留、删书清除，语义不变。
- 本轮不恢复点工具结果跳转。

## Acceptance Criteria

- [ ] 选中点「高亮」立即落下，浮层不出现色板或笔记框。
- [ ] 点原文高亮能打开操作弹层，可改色、写笔记、删除；删除后原文和列表都没有这条。
- [ ] 点原文高亮不会翻页。
- [ ] 能给高亮写笔记、改笔记、留空；重开该书后笔记仍在。侧栏能看出有笔记。
- [ ] 能把高亮改成色板里的另一种颜色；原文和侧栏颜色一致；重开后仍对。
- [ ] 新划线使用上次选过的颜色；重启应用后未再选色时回到默认琥珀黄。
- [ ] 旧的无颜色/无笔记高亮仍能打开、绘制、删除，`get_annotations` 不报 corrupt。
- [ ] `list_annotations` 返回高亮 `color` 以及非空 `note`；助手仍不能创建或修改标注。
- [ ] 选中浮层「高亮」「问 agent」、书签、抽屉互斥行为保持。
- [ ] 没有导出、没有书签笔记、没有自定义色值。
- [ ] `npm test` 与相关 Rust 测试通过。

## Out of Scope

- 导出划线
- 书签改名 / 书签笔记 / 书签颜色
- 自定义色值、下划线/波浪线样式
- 助手创建或修改标注
- 恢复「点工具结果跳转」
- 云同步、全文搜索标注、跨书标注列表
- 上次颜色写入 `preferences.json` / `localStorage`

## Technical Notes

- 跨层字段：`HighlightRecord.color`（闭合语义 id）、`HighlightRecord.note`（可选纯文本）。Rust / TS / `list_annotations` 映射必须一致。
- 实现后同步 `.trellis/spec/` 里标注「单色、无笔记」的表述。
