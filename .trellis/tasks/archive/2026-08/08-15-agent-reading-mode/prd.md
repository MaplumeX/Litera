# Agent reading mode

## Goal

用户可以在「书为主」和「对话为主」之间切换。Agent 阅读模式里，主区域是类似 ChatGPT 的对话，左侧是会话列表，右侧是完整阅读器，方便对照原文提问。

## Background

当前阅读页是书为主、对话为辅：`App.tsx` 可调整分栏，默认阅读器约 78%、聊天约 22%，聊天默认折叠。会话按书绑定，列表是聊天面板里的覆盖层。划词「问 Agent」会展开聊天并填入输入框。

`ReaderView` / `ChatPanel` 切换时若卸载，会重新打开 EPUB 并打断 `fillInput`。现有约定是各挂载一份，折叠用 `hidden` + 宽度为 0。

## Requirements

- R1. Agent 阅读模式：主区域为对话（消息流 + 底部输入），视觉接近常见聊天产品。
- R2. 该模式左侧为真实会话列表（可收起），不是盖住对话的覆盖层。
- R3. 该模式右侧为当前打开的书，默认可对照阅读。
- R4. 现有「书为主 + 可折叠侧栏聊天」保留；Agent 模式是第二种模式，不是替换。
- R5. 设置里可选择应用默认模式（阅读 / Agent）。从未改过时默认是阅读模式。
- R6. 阅读页顶栏可在两种模式间切换。
- R7. 每本书记住上次模式；打开书时该书记忆优先于应用默认。改应用默认不改写已有单书记忆。
- R8. Agent 模式侧边书是完整阅读器：翻页、进度条、划词问 Agent、目录、书签、高亮都可用。目录/书签仍是盖在书上的抽屉，不是新的一栏。划词填入当前对话。
- R9. 两种模式共用该书会话；切换模式不新建会话、不丢当前对话。
- R10. 会话列表固定宽度、可收起（收起后不是覆盖层）。右侧书可拖拽调宽，也可收起以便专心聊天。默认三者都打开：列表约 240px，书约 38%，中间给对话。
- R11. 切换模式不得卸载 `ReaderView` 或 `ChatPanel`。

## Out of scope

- 改写 Agent 运行时、模型配置、压缩策略。
- 跨书的全局会话列表（会话仍按书隔离）。
- 重做划词、高亮、书签、目录的数据模型。
- 书库增加「用 Agent 打开」的第二条入口。
- 窄窗口专门的单栏移动布局。

## Technical notes

- 应用默认模式不要写入 `preferences.json`（`deny_unknown_fields` 会让旧版本把文件当成损坏并重置主题/排版）。与 locale 一样放 `localStorage`。
- 单书上次模式是持久阅读状态，走 `library.json` 的可选字段 + `update_reading_state`，模式与 `lastOpenedAt` 相同：`serde(default)`，不升 `schemaVersion`。
- 书籍侧栏宽度、聊天侧栏宽度属 UI chrome，走 `localStorage`（与 `toc-sidebar-width`、现有分栏宽度一致）。
- 列表/书的收起状态按现有 `chatCollapsed` / `tocVisible`：进程内即可，不必跨启动记住。再次进入 Agent 模式时列表和书都打开。

## Acceptance Criteria

- [ ] AC1. 打开书后仍能使用现有「书为主 + 侧栏聊天」；未改设置、该书无模式记忆时进入阅读模式。
- [ ] AC2. Agent 模式为左会话列表、中对话、右完整阅读器；默认列表约 240px、书约 38%。
- [ ] AC3. 顶栏可在两种模式间切换；切换后对话仍是同一会话，输入框草稿还在。
- [ ] AC4. 设置里可改默认模式；无单书记忆的书打开时用该默认；改默认不改变已记住模式的书。
- [ ] AC5. 在某本书上切换模式后，下次打开该书进入上次的模式。
- [ ] AC6. Agent 模式侧边书可翻页、看进度、划词问当前对话，并打开目录 / 书签 / 高亮。
- [ ] AC7. Agent 模式可收起会话列表、可拖拽或收起右侧书；收起列表后对话仍完整可见，不是被浮层盖住。
- [ ] AC8. 切换模式不会重新打开 EPUB（`ReaderView` 不卸载），折叠的聊天面板也保持挂载。
