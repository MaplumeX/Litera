# Allow choosing real reader fonts

## Goal

用户能从本机已安装字体里选一款，用在全部阅读正文上，而不只是浏览器默认的「衬线 / 无衬线 / 等宽」。

## Background

设置页排版分类已有字体三档按钮：`serif` / `sans-serif` / `monospace`。作用域与其他排版项相同：书库改全局默认，阅读中改当前书，可「恢复默认」。生效只走 `generateStylesCss` → `view.renderer.setStyles`，把 `font-family` 写进 iframe 的 `html, body`。

前后端目前把字体当成封闭枚举（`FONT_FAMILIES` / `isFontFamily`，以及 `preferences.rs` 与 `library.rs` 的 `VALID_FONT_FAMILIES`）。未知值保存会被拒；前端读到未知值会丢掉并回落到 `serif`。`preferences.json` 启动时若 `is_supported()` 失败会整份写成默认，因此校验必须放宽到「合法字体名」，不能把具名字体当成损坏文件。

上一轮 `08-13-reader-settings-fine-tune` 把「自定义字体、系统字体选择器」标为 out of scope。设置弹窗固定 `768×40rem`（视口不够时收），排版区在典型窗口里不应因字体列表整页滚动。

## Requirements

### R1 从系统字体里选一个字体族

- 设置页「字体」从三档按钮改成本机已安装字体的可搜索选择器。
- 列表按字体族去重，不把同一族的 Bold / Italic 拆成多项。
- 现有三档通用族固定出现在列表顶部，作为不依赖本机具名字体的回退选项。
- 选项用该字体自身预览。
- 正文只用这一个字体族。不分开设置中文 / 西文。

### R2 作用域与生效

- 书库改全局默认，阅读中改当前书，可「恢复默认」。
- 只影响阅读正文，不影响应用外壳（设置页、书库、聊天）的界面字体。
- 选中后已打开的书立刻（或回到阅读页时）使用该字体族。

### R3 兼容与缺失字体

- 已保存的 `serif` / `sans-serif` / `monospace` 继续按原意生效。
- 已保存的具名字体在本机被卸载或不存在时：CSS 回退到 `serif`，设置里仍显示已保存的名字并标明不可用。重新装回后自动恢复，不改写偏好。
- 非法或空的字体名拒绝保存。合法名字的长度和字符集必须有上限，不能让偏好文件被整份重置。

### R4 兼容存储

- `preferences.json` 保持 `schemaVersion = 1`。旧文件（三档通用族或缺少新字段）必须能读，禁止「不认识就整份重置」。
- `update_reading_state` 仍整对象替换 `settings`；「恢复默认」= 快照里去掉该键。

## Out of scope

- 导入 `.ttf` / `.otf`、打包内置字体
- 中文 / 西文两套字体
- 字重 / 斜体作为独立设置（跟随字体族默认样式）
- 自定义主题、亮度、定时夜间模式
- 设置页假文预览、阅读中排版浮层
- 改字号 / 行距 / 边距等已有精调项
- 改 LLM 配置、书签、高亮、TTS
- 改应用外壳字体

## Acceptance Criteria

- [ ] 设置页字体控件能列出本机已安装字体族，并能搜索后选中。
- [ ] 列表顶部仍能选衬线 / 无衬线 / 等宽。
- [ ] 书库改字体后，新开一本没有覆盖的书使用该默认字体。
- [ ] 阅读中改字体只影响当前书；「恢复默认」后回到全局默认。
- [ ] 选中的具名字体写入阅读 CSS 的 `font-family`，正文可见更换。
- [ ] 已存的三档通用族仍有效。
- [ ] 已存具名字体在本机不存在时，正文回退衬线，设置项仍显示原名且标为不可用；装回后恢复。
- [ ] 应用外壳字体不随这项改变。
- [ ] 设置弹窗固定尺寸约定不被破坏（典型窗口排版区不必为字体列表整页滚动）。
- [ ] `npm test` + `npm run build` 通过；相关 Rust 测试通过。
