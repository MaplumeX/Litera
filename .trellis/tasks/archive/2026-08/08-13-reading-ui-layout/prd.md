# Optimize reading UI layout

## Goal

让阅读页以正文为中心：打开书先看到书，目录和对话按需出现，而不是和正文抢同一层空间。

## User Value

打开书的第一眼是全宽正文。目录是覆盖抽屉，对话默认收起；要点助手或选段「问 agent」时再并排打开。回书库、换书时记住本次进程里的开/关，重启回到阅读优先默认。

## Background / Confirmed Facts

- `08-12-modernize-reader-ui` 只做了图标化并去掉底栏翻页，当时明确「分栏骨架不变」。
- 当前阅读页在 `src/App.tsx:389-497`：顶栏是返回 / **Litera**（`text-lg font-bold`）/ 灰色截断书名 / `w-24` 进度 / 目录 / 字体 / 对话。目录打开是固定 `w-56` 第三列（`:445-448`），不进 `Group`。对话默认 `65/35`（`:466-481`）。
- 三层 header：App 顶栏、`TocSidebar`「目录」、`ChatPanel`「阅读助手」。
- 折叠对话时 `ChatPanel` 被卸载（`App.tsx:451-485`），`chatRef.fillInput` 在折叠态无效。`chatCollapsed` 回书库不重置；`tocVisible` 会重置（`:309`）。偏好只存主题。
- 设置入口已拆分：顶栏 `Type` → `SettingsDialog`；对话齿轮 → `AgentConfigDialog`。
- 翻页已由键盘 ←/→ + foliate 点击/滚轮承担。
- 书库、Chat 气泡/输入区、sidecar/agent 协议不在本轮范围内。
- 分支：`feat/reading-ui-layout-optimization`。

## Key Decisions

- **D1** 方案 B：阅读优先重组。不采用 A（只改顶栏）或 C（自动藏顶栏）。
- **D2** 对话默认收起；打开后约 22–25%，可拖、可再收。
- **D2b** 收起时点「问 agent」：先打开对话再填入选段。已打开则只填入。
- **D3** 目录/对话开/关只记本次进程（换书、回书库再打开保持）。重启回到默认：目录关、对话收起。不写偏好。

## Requirements

### R1 顶栏以书名为中心

- 阅读页顶栏主标题是书名（truncate）。不再显示品牌名 `Litera`。
- 右侧一组图标：目录、字体、对话。激活态一律 `secondary`，关闭 `ghost`。
- 返回书库按钮保留。

### R2 进度单独成条

- 章节名 + 百分比从图标堆里拆出，放到顶栏正下方的通栏细进度条。
- 不要求点击跳转。

### R3 目录是覆盖抽屉

- 默认关闭。打开时从左侧盖在正文上，不是固定第三列，不永久挤窄阅读区。
- 点章节：跳转并关闭抽屉。点抽屉外或再点目录按钮：关闭。
- 目录数据仍来自 `book.toc`。

### R4 对话默认收起，按需并排

- 打开书时（含冷启动后第一次）对话收起，正文全宽。
- 点顶栏对话按钮打开并排面板，默认约 22–25%，可拖，最小宽度不低于现有可用性。
- 同一进程内换书、回书库再打开：保持用户上次的开/关，不因换书重置。
- 选段「问 agent」：收起则打开并 `fillInput`；已打开只 `fillInput`。

### R5 既有能力保留

- 返回书库、字体/主题、键盘翻页、位置恢复、对话收发/会话列表、`ChatPanelHandle.fillInput` 契约。
- 三主题只用现有 token。图标继续 lucide + `aria-label`。

## Acceptance Criteria

- [ ] 打开书后顶栏主标题是书名，没有品牌名压过书名。
- [ ] 进度（章节 + 百分比）在顶栏下方通栏细条上，不和图标挤在同一小段。
- [ ] 打开目录时是覆盖抽屉，阅读区不被固定 224px 列永久挤窄；点章节后抽屉关闭并跳转。
- [ ] 冷启动后第一次打开书：对话收起，正文全宽。
- [ ] 点顶栏对话按钮后并排打开（约 22–25%），可拖、可再收；按钮激活态与目录一致（`secondary`/`ghost`）。
- [ ] 同一进程内打开对话后回书库再打开任意书：对话仍开着。重启应用后再打开书：对话重新收起。目录同理。
- [ ] 对话收起时点「问 agent」：对话打开，选段在输入框。已打开时只填入。
- [ ] 返回书库、目录跳转、字体/主题、键盘翻页、位置恢复、聊天收发仍可用。
- [ ] `npm test` + `npm run build` 通过。

## Out of Scope

- 书库页布局。
- Chat 消息气泡 / 输入区 / 空状态再设计。
- 书签、文内搜索、高亮、笔记。
- 进度条点击跳转、当前章节高亮、目录钉住为列。
- 自动隐藏顶栏（方案 C）。
- 把目录/对话开/关写入偏好或磁盘。
- sidecar / agent 协议、设置数据模型。
- 移动端适配、主题 token 重做。

## Chosen Layout

```
默认（冷启动后第一次打开书）：

+------+----------------------------------------+----------+
| 返回 | 书名                                    | 目录 字体 对话 |
+------+----------------------------------------+----------+
| ===================== 第3章 · 42% =======================|
+----------------------------------------------------------+
|              正文全宽                                    |
+----------------------------------------------------------+

打开目录（覆盖，不永久挤窄）：

+--+-------------------------------------------------------+
|目|              正文仍几乎全宽                            |
|录|                                                       |
+--+-------------------------------------------------------+

打开对话（并排，约 22–25%）：

+---------------------------------------+------------------+
| 正文                                  | 对话             |
+---------------------------------------+------------------+
```
