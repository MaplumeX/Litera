# Reader bookmarks, highlights, and progress jump

## Goal

让阅读页补上一般阅读器的两块核心能力：读者能钉住位置、划出原文，并能在阅读页直接跳到全书任意进度。

## User Value

现在选中文本只能问助手，阅读页也没有可操作的进度。读者要找一段、回到某处，只能翻页或点目录。补上书签/高亮和进度跳转后，Litera 在「自己读书」这件事上才像一台阅读器；助手仍然是附加能力，不是唯一出口。

## Background / Confirmed Facts

- 来源：对照一般阅读器的缺口，用户要做建议优先级的 **2. 高亮 + 书签** 和 **3. 阅读页可跳转的进度**。书内搜索、滚动模式、多格式等不在本任务。
- 早期任务把书签、高亮、笔记、进度条拖拽标为 v2（`08-12-reader-enhancement`、`08-12-library-reader-ux`、`08-13-reading-ui-layout`）。
- `08-13-remove-reader-progress-bar` 删掉阅读页常驻进度条，当时规定「不换成发丝线，也不把百分比塞回顶栏」。用户在本任务明确改口：要永远显示可跳转细条。
- 删条前的形态（`src/App.tsx` 当时的 `ReaderProgressBar`）：顶栏正下方通栏，全书 `fraction` 细条 + `chapterLabel · {pct}%`。`chapterLabel` 来自 `progress.label ?? \`Chapter ${progress.index + 1}\``。当时不可点击。
- `progress` state 仍在：`chapterHref` 给 `ChatPanel`，`fraction` 经 debounce 写 `lastFraction`。书库卡片用 `BookCard` 显示进度。
- `ReaderView` 选中后只浮出「问 agent」（`src/components/ReaderView.tsx`）。
- 已有 `goToFraction` / `goTo`（`ReaderViewHandle`）。目录是阅读区上的左侧覆盖抽屉（`TocSidebar`），点章节后关闭。
- `update_reading_state` 只写 `lastFraction` 和 `settings`。`BookRecord` 无标注字段，且 `deny_unknown_fields`。覆盖导入保留进度、设置、对话；删除书会删 `books/<bookId>/`。
- 前端无全局状态库。目录/对话开合只活在进程内存。
- 现有 frontend spec 写着「不要加阅读页进度条」。本任务改产品决定后，实现阶段要同步改 `.trellis/spec/frontend/component-guidelines.md` 与 `state-management.md`。
- `src/foliate-js` 在本工作区未检出。高亮定位/绘制 API 见 `research/`。

## Key Decisions

- **标注 MVP = 书签 + 单色高亮。** 无笔记、无多色、无导出。
- **列表入口 = 顶栏「标注」按钮。** 打开与目录相同的左侧覆盖抽屉，内部分书签、高亮两段。目录只管章节。同时只开一个左侧抽屉：打开标注则关目录，反之亦然。
- **加书签 = 抽屉顶部「添加书签」。** 钉当前阅读位置，不依赖选中文字。顶栏按钮只负责开闭抽屉。
- **加高亮 = 选中浮层增加「高亮」，保留「问 agent」。**
- **进度条 = 顶栏下方常驻细条，可点可拖。** 展示章节名 + 百分比 + 填充；跳转走 `goToFraction`。百分比不进顶栏按钮区。书库卡片进度不变。

## Requirements

### R1 书签

- 标注抽屉顶部能把当前阅读位置存成书签。
- 书签按书持久化；重开应用、重开该书后仍在。
- 列表展示可识别的标签（章节名，或当前位置百分比）。
- 点一项跳到该书签位置。
- 能删除书签；删除后列表不再出现。
- 覆盖导入同一本书时书签保留。删除该书时书签一并消失。

### R2 高亮

- 选中正文后能加上一道单色高亮；同一浮层仍能「问 agent」。
- 高亮在翻页、关书再开、重开应用后仍画在原文上。
- 标注抽屉的高亮段列出摘录；点一项跳到该高亮。
- 能删除高亮；删除后原文颜色消失。
- 覆盖导入同一本书时高亮记录保留（新文件对不上的高亮可以画不出，但记录不丢）。删除该书时高亮一并消失。

### R3 标注抽屉

- 阅读页顶栏在目录和字体之间有「标注」图标按钮；激活态与目录按钮相同（`secondary` / `ghost`）。
- 打开后是覆盖在阅读区上的左侧抽屉，不把正文挤成固定列。
- 抽屉内分「书签」「高亮」两段；空段有空状态。
- 点遮罩、Esc、或再点「标注」关闭。点列表跳转后关闭（与目录一致）。
- 开闭状态只活在当前进程，不写磁盘。回书库再打开书时保持；重启后关闭。

### R4 进度跳转

- 阅读页顶栏正下方永远显示进度细条：章节名、百分比、填充。
- 点击或拖动细条跳到对应全书 fraction；跳转后正文与条上数字一致。
- 翻页、目录跳转、书签/高亮跳转后，细条跟随更新。
- 不把百分比塞进顶栏图标区。不改书库卡片进度。

### R5 既有行为

- 「问 agent」、目录、排版、对话开合、位置恢复、覆盖/删除书的现有语义不变（除本任务声明的标注保留/删除）。

## Acceptance Criteria

- [ ] 标注抽屉顶部能给当前位置加书签；重开该书后书签仍在，点击可跳回。
- [ ] 能删除书签，删除后列表不再出现该项。
- [ ] 选中正文能加上单色高亮；翻页和重开书后高亮仍在原文上。
- [ ] 能从高亮列表跳到对应原文，并能删除高亮。
- [ ] 选中浮层同时有「高亮」和「问 agent」；问 agent 行为与现在一致。
- [ ] 顶栏有「标注」按钮，打开左侧覆盖抽屉，内部分书签/高亮；与目录互斥，不永久挤窄正文。
- [ ] 没有笔记输入、没有多种高亮颜色、没有导出。
- [ ] 覆盖同一本书后书签/高亮记录仍在；删除书后标注不再出现。
- [ ] 阅读页顶栏下方有常驻进度细条，显示章节与百分比。
- [ ] 点击或拖动细条能跳到对应位置；跳转后条上的百分比与正文位置一致。
- [ ] 百分比没有出现在顶栏按钮区；书库卡片进度展示不变。
- [ ] `npm test` 与 `npm run build` 通过。

## Out of Scope

- 书内全文搜索
- 多色高亮、笔记正文、导出划线
- 云同步、TTS、词典、滚动模式、双栏
- 悬停才出现的进度条、顶栏弹出滑块
- 助手协议、sidecar、会话
- 把标注开闭写入偏好或磁盘
- 当前章节在目录树里高亮
