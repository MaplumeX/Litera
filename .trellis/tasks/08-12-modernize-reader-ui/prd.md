# 现代化阅读器 UI 重构

## Goal

将 Litera 的阅读器界面从"文字按钮平铺散落"的旧形态,重构为符合现代阅读软件(Apple Books、Readwise Reader、微信读书)惯例的"图标化 + 分组 + 集成进度条"形态,提升视觉一致性和沉浸感。

## Background

### 当前问题(证据)

阅读当前 UI 存在"按钮散落、暴露在四处"的问题:

1. **阅读器顶栏**(`src/App.tsx:185-230`)—— 4 个文字标签按钮并排暴露:
   `[← 书库]  Litera · 书名   [☰ 目录] [Aa] [显示对话]`
   - 无图标、无分组、视觉重量大
2. **阅读器底栏**(`src/App.tsx:240-254`)—— 翻页按钮独占整行:
   `[上一页]  第3章 · 42%  [下一页]`
   - 文字按钮笨重,占据垂直空间;现代阅读器用进度条替代
3. **聊天面板头部**(`src/components/ChatPanel.tsx:140-170`)—— 按钮堆叠:
   `[☰ 会话] 阅读助手  📖 已就绪 [⚙ 设置]`
   - 狭窄右侧栏里文字按钮 + 状态文字混挤
4. **`Aa` 控件触发器**(`src/App.tsx:208`)—— 裸露文字"Aa"按钮,与其余按钮风格不统一
5. **书库工具栏**(`src/components/LibraryView.tsx:79-96`)—— "导入"文字按钮,未图标化

### 技术现状(代码证据)

- `package.json` 已依赖 `lucide-react ^1.31.0`,但全项目**零使用**
- `src/components/ui/button.tsx` 已定义 `icon` / `icon-sm` / `icon-xs` size 变体,支持图标按钮
- shadcn/ui new-york 风格,`components.json` 指定 `iconLibrary: lucide`
- 阅读器基于 `foliate-js`,已支持键盘/滚轮翻页(`ReaderView.tsx` prev/next 方法)
- 现有布局:`react-resizable-panels` 三栏(目录 | 阅读器 | 聊天)

### 同类产品研究结论

| 产品 | 顶栏 | 底栏 | 翻页 | 按钮形态 |
|------|------|------|------|----------|
| Apple Books iOS16+ | 仅关闭+多功能 | 进度条+目录融合 | 点击区域/滑动 | 图标,多功能收纳 |
| Readwise Reader | 图标分组 | 进度条+翻页 | 键盘/滚轮 | 图标分组 |
| 微信读书 | 少量图标 | 进度条 | 滑动 | 镂空 icon |
| Apple HIG | 逻辑分组 | — | — | 图标,溢出菜单 |

**共识模式**:图标化 + 逻辑分组 + 进度条集成 + 非必要操作收纳 + 翻页用点击/键盘而非显式按钮。

## Requirements

### R1 阅读器顶栏:图标化 + 分组
- 将 `← 书库`、`☰ 目录`、`Aa`、`显示/隐藏对话` 全部改为 lucide 图标按钮(`ghost` + `icon-sm`)
- 左侧一组(返回),右侧一组(目录、Aa、对话),中间显示书名
- 激活态(tocVisible / controlsOpen / chatCollapsed)用背景色高亮,非文字变化

### R2 阅读器底栏:移除独立翻页按钮,改为进度条
- 移除"上一页/下一页"文字按钮独占的 footer 行
- 进度信息(章节 · 百分比)以细条形式融入顶栏或一个细底栏
- 翻页改由 foliate 原生支持(键盘方向键/滚轮/点击区域)
- (翻页按钮的具体处理见 Open Questions)

### R3 聊天面板头部:图标化精简
- `☰ 会话`、`⚙ 设置`、`重启助手` 改为 lucide 图标按钮(`ghost` + `icon-xs`)
- 状态文字("📖 已就绪"/"等待书籍…")弱化为小字号,不与按钮混排
- 标题"阅读助手"保留

### R4 `Aa` 控件触发器:图标化
- 触发按钮用 `Type`(或 `A` 字形)图标,与顶栏其他按钮风格统一
- 弹出面板(`ReaderControls.tsx`)内部设计已合理,保持

### R5 书库工具栏:导入按钮图标化(轻量)
- "导入"按钮加 lucide `Plus` / `Upload` 图标,文字可选保留
- 搜索框保持

### R6 全局:引入并统一使用 lucide-react 图标
- 安装/确认 `lucide-react` 可用(已在依赖)
- 所有新增图标按钮使用 `Button` 的 `icon*` size 变体

## Acceptance Criteria

- [ ] 阅读器顶栏无文字标签按钮(返回、目录、Aa、对话全部图标化),按左右两组分组
- [ ] 阅读器底部不再有"上一页/下一页"文字按钮独占行
- [ ] 进度信息(章节 + 百分比)在顶栏或细底栏以集成形式呈现
- [ ] 聊天面板头部按钮全部图标化,无 `☰`/`⚙` 字符按钮
- [ ] `Aa` 触发器为图标按钮,与同组按钮风格一致
- [ ] 翻页功能(键盘/滚轮/点击)在移除显式按钮后仍可用
- [ ] `lucide-react` 在项目中实际被引用(至少 5 个图标)
- [ ] `npm run build` 通过,无类型错误
- [ ] 现有功能不受损:打开书、目录跳转、字体/主题切换、聊天收发、会话切换

## Out of Scope

- 重新设计整体配色/主题系统(仅复用现有 token)
- 移动端适配(当前为 Tauri 桌面应用)
- 重新设计聊天面板的消息气泡/输入区样式
- 重新设计书库的卡片网格布局
- 新增功能(书签、搜索、标注等)

## Decisions

- **Q1 翻页按钮处理**:采用方案 A —— 删除整个底栏 footer,翻页改由键盘 ←/→、滚轮、foliate 点击区域完成;进度信息(章节 + 百分比)移至顶栏右侧以细进度条形式集成。

## Technical Notes

- foliate-js 的 prev/next 方法仍可通过键盘事件或隐藏的点击区域调用,无需暴露按钮
- `react-resizable-panels` 布局不变,仅改头部/底部
- 图标按钮的 `aria-label` 需补齐以保持可访问性
